# Kortteli Brand Palette v1

Kortteli is a warm, calm and trust-first hyperlocal neighborhood platform.  
The UI should feel like a safe local community, not a marketplace, social media feed or dashboard.

## Core colors

| Role | Color |
|---|---|
| App background | `#fbf8f2` |
| Warm card background | `#fffdf9` |
| Primary CTA | `#4a3b2f` |
| Primary CTA hover | `#3f3227` |
| Main text | `#1f1a17` |
| Secondary text | `#6b625c` |
| Soft border | `rgba(120,100,80,0.08)` |
| Trust / success | `#6b8b72` |
| Warm highlight | `#f6efe4` |

## UI rules

- Use warm sand and off-white backgrounds.
- Avoid pure black, pure white and cold grays.
- Primary buttons use espresso brown.
- Trust and success states use muted sage green.
- Borders should be soft and subtle.
- Shadows should be diffused, not harsh.
- Rounded geometry is part of the product identity.
- Avoid dashboard-like layouts when possible.
- Avoid marketplace seller-page energy.
- The UI should feel human, calm and local.

## Tone of voice

Kortteli should sound:
- warm
- clear
- human
- low-pressure
- trustworthy

Avoid:
- sales language
- gamification language
- corporate wording
- social media style engagement language

## Design question for every new component

“Does this feel like Kortteli?”

If not, simplify it, warm it up, and reduce the marketplace feeling.
